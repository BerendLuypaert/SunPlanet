# Sun Planet

Statische website voor Sun Planet Heusden-Zolder.

## Lokaal bekijken

Open `index.html` rechtstreeks in de browser of gebruik de VS Code-extensie Live Server en klik op **Go Live**. Er is geen buildstap nodig.

## GitHub Pages

Deze repo bevat een workflow in `.github/workflows/pages.yml` die de site vanuit de root publiceert naar GitHub Pages bij elke push naar `main`.
